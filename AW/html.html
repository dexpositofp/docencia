HTML - Complete Guide

HTML (HyperText Markup Language) is the standard language for creating web pages. It's not a programming language, but a markup language that defines the structure and content of web pages using tags. This guide is designed for vocational students who want to learn HTML from scratch.

Did you miss class? Don't worry.
This guide is designed so you can learn HTML on your own, with detailed explanations, real-world examples, and self-assessment exercises. Read carefully and practice each concept before moving to the next one.

1. Introduction to HTML

What is HTML?

HTML is a markup language that uses tags to structure the content of a web page. Each tag has a specific semantic meaning that tells the browser how to interpret and display the content.

Analogy to understand HTML:
Think of HTML as the blueprint of a house. The blueprint defines where each room, door, and window goes, but it doesn't say what color to paint the walls or what furniture to put in. That's what CSS does (design) and JavaScript (functionality, like turning on lights).

Brief History

  • 1991: Tim Berners-Lee creates HTML as part of the World Wide Web
  • 1995: HTML 2.0 - First standard version
  • 1999: HTML 4.01 - Stable version for many years
  • 2014: HTML5 - Current standard, native multimedia and APIs
  • Today: HTML Living Standard - Continuous evolution

Why is HTML Important?

HTML is the foundation of the ENTIRE web:

  • Universal: Works on any device with a browser
  • Accessible: Assistive technologies read semantic HTML
  • SEO: Search engines understand HTML structure
  • Foundation for everything: CSS and JavaScript are applied on top of HTML
  • Longevity: An HTML page from 1995 still works today

Tools Needed

To write HTML you only need:

  1. Text editor: VS Code, Sublime Text, Notepad++
  2. Web browser: Chrome, Firefox, Safari, Edge
  3. Browser DevTools: Press F12 to inspect code

Recommendation: Use VS Code with these extensions:
- Live Server (automatic refresh)
- HTML CSS Support (autocomplete)
- Prettier (automatic formatting)

2. Basic Structure of an HTML Document

Anatomy of an HTML Tag

HTML tags have this structure:

<tagName attribute="value">
  Content
</tagName>

Components:

  • Opening tag: <p>
  • Attributes: class="highlight"
  • Content: The text or internal elements
  • Closing tag: </p>

Self-closing tags (void elements):
Some tags have no content or closing tag:
<img>, <br>, <hr>, <input>, <meta>, <link>

The Minimal HTML Document

Every HTML5 document must have this structure:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
</head>
<body>
  <!-- Here goes the visible content -->
  <h1>Hello World</h1>
  <p>My first web page.</p>
</body>
</html>

Explanation of Each Part

1. <!DOCTYPE html>

Declaration that tells the browser this document uses HTML5. MUST be the first line of the file.

2. <html lang="en">

Root element that contains the entire document. The lang attribute specifies the language (important for SEO and accessibility).

Examples: lang="en" (English), lang="es" (Spanish), lang="fr" (French)

3. <head>

Section that contains metadata (information about the document). The content of the <head> is NOT visible on the page.

Common elements in the <head>:
<head>
  <!-- Character encoding (ALWAYS UTF-8) -->
  <meta charset="UTF-8">

  <!-- Viewport for responsive design -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">

  <!-- Title (appears in browser tab) -->
  <title>My Website</title>

  <!-- Description for search engines -->
  <meta name="description" content="Brief site description">

  <!-- Author -->
  <meta name="author" content="Your Name">

  <!-- Tab icon (favicon) -->
  <link rel="icon" type="image/x-icon" href="/images/favicon.ico">

  <!-- CSS stylesheet -->
  <link rel="stylesheet" href="styles.css">

  <!-- Deferred JavaScript (loads after HTML) -->
  <script src="script.js" defer></script>
</head>

4. <body>

Contains ALL the visible content of the page: text, images, videos, forms, etc.

Loading order:
1. Browser downloads the HTML
2. Reads the <head> and downloads CSS/JS
3. Renders the <body> from top to bottom
4. JavaScript with defer executes at the end

HTML Comments

Comments are not displayed in the browser:

<!-- This is a single-line comment -->

<!--
  This is a multi-line
  comment
-->

<!-- TODO: Add image here -->

Warning: HTML comments are visible in the source code (right-click → View page source). NEVER put passwords, API keys, or sensitive information in HTML comments.

Character Encoding

Always use UTF-8 encoding to support all international characters: 

<meta charset="UTF-8">

This allows you to use characters like: é, ñ, ü, 中文, العربية, etc.

3. Semantic Tags and Page Structure

HTML5 introduced semantic tags: tags that describe the meaning of their content, not just their appearance.

Why Does Semantics Matter?

  • SEO: Search engines better understand the structure
  • Accessibility: Screen readers navigate by sections
  • Maintainability: Code is easier to understand
  • Web standards: Recognized best practices

Typical Page Structure with Semantic HTML5

<body>
  <header>
    <nav>
      <ul>
        <li><a href="#">Home</a></li>
        <li><a href="#">About Us</a></li>
        <li><a href="#">Contact</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <header>
        <h1>Article Title</h1>
        <p><time datetime="2026-10-03">October 3, 2026</time></p>
      </header>

      <section>
        <h2>Introduction</h2>
        <p>Introduction content...</p>
      </section>

      <section>
        <h2>Main Content</h2>
        <p>Main content...</p>
      </section>

      <footer>
        <p>Author: John Smith</p>
      </footer>
    </article>

    <aside>
      <h3>Related Articles</h3>
      <ul>
        <li><a href="#">Article 1</a></li>
        <li><a href="#">Article 2</a></li>
      </ul>
    </aside>
  </main>

  <footer>
    <p>© 2026 My Website</p>
  </footer>
</body>

Main Semantic Tags

Tag Purpose Typical Use
<header> Header of document or section Logo, navigation, main title
<nav> Main navigation Main menu, breadcrumbs
<main> Main content (unique) The central content of the page
<article> Independent content Blog post, news article, comment
<section> Thematic section Chapters, tabs, numbered sections
<aside> Tangential content Sidebar, related content, ads
<footer> Footer of page/section Copyright, links, contact info

Common Mistake

BAD: Using <div> for everything

<div class="header">
  <div class="navigation">...</div>
</div>

GOOD: Use semantic tags

<header>
  <nav>...</nav>
</header>

Why? Semantic tags improve SEO, accessibility, and code readability.

When to Use Each Tag?

<header>

Introductory content for a page or section. Can contain logos, headings, navigation.

<header>
  <h1>My Website</h1>
  <p>Welcome to my site</p>
</header>

<nav>

Contains navigation links. Use only for main navigation areas.

<nav>
  <ul>
    <li><a href="home.html">Home</a></li>
    <li><a href="about.html">About</a></li>
  </ul>
</nav>

<main>

Main content of the page. Only ONE per page.

<main>
  <h1>Welcome</h1>
  <p>This is the main content...</p>
</main>

<footer>

Footer for a page or section. Typically contains copyright, contact info, links.

<footer>
  <p>© 2026 My Company</p>
  <p>Contact: info@example.com</p>
</footer>

4. Text and Formatting

Headings

HTML has 6 levels of headings: <h1> to <h6>

<h1>Main Title (only 1 per page)</h1>
<h2>Level 2 Subtitle</h2>
<h3>Level 3 Subtitle</h3>
<h4>Level 4 Subtitle</h4>
<h5>Level 5 Subtitle</h5>
<h6>Level 6 Subtitle</h6>

Heading Rules:

  • Only 1 <h1> per page (the main title)
  • Don't skip levels: after <h2> comes <h3>, not <h5>
  • Don't use headings just to make text bigger (use CSS)
  • Headings create the hierarchical structure of the page

Paragraphs and Line Breaks

<p>This is a text paragraph.</p>
<p>This is another paragraph.</p>

<p>First line.<br>
Second line in the same paragraph.</p>

Differences:

  • <p>: Creates paragraph with vertical space before/after
  • <br>: Line break WITHOUT additional vertical space

Horizontal Rule

The <hr> tag creates a thematic break (horizontal line):

<p>Section 1 content</p>
<hr>
<p>Section 2 content</p>

Text Formatting

Semantic Emphasis (with meaning)

<strong>Strong importance (usually bold)</strong>
<em>Emphasis (usually italic)</em>
<mark>Highlighted text (like yellow marker)</mark>
<small>Small print (fine print)</small>
<code>Inline code like variables</code>

Visual Formatting (without semantic meaning)

<b>Bold text (no semantic importance)</b>
<i>Italic text (no semantic emphasis)</i>
<u>Underlined text (avoid, looks like links)</u>
<s>Strikethrough text</s>

Prefer semantic tags:
✅ Use <strong> for importance
✅ Use <em> for emphasis
❌ Avoid <b> and <i> (use CSS for visual style)

Difference Between <b> / <strong> and <i> / <em>

Tag Meaning When to Use
<strong> Strong importance Important content (warnings, key points)
<b> Just visual bold Keywords, product names (no importance)
<em> Emphasized stress Spoken emphasis, stress on word
<i> Just visual italic Technical terms, foreign words, thoughts

Preformatted Text

The <pre> tag preserves spaces and line breaks:

<pre>
This    text     preserves
   all   spaces
      and line breaks
</pre>

5. Links and Images

Links (Hyperlinks)

Links are the foundation of the web. They allow navigation between pages.

Anatomy of a Link

<a href="destination.html">Link text</a>

Important attributes:

  • href: Destination URL (required)
  • target: Where to open the link
  • title: Tooltip on hover
  • download: Downloads file instead of opening it

Types of Links

<!-- Link to another page on same site (relative) -->
<a href="contact.html">Contact</a>

<!-- Link to another site (absolute) -->
<a href="https://www.example.com">Visit Example</a>

<!-- Link to section on same page (anchor) -->
<a href="#section1">Go to Section 1</a>
<section id="section1">...</section>

<!-- Email link -->
<a href="mailto:info@example.com">Send Email</a>

<!-- Phone link -->
<a href="tel:+1234567890">Call Us</a>

Absolute vs Relative URLs

Type Example When to Use
Absolute https://www.example.com/page.html Links to external websites
Relative page.html or ../page.html Links within your own website

Target Attribute

<!-- Open in new tab -->
<a href="https://example.com" target="_blank">Open in New Tab</a>

<!-- Open in same tab (default) -->
<a href="page.html" target="_self">Open Here</a>

Security tip: When using target="_blank", also add rel="noopener noreferrer" for security:

<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  Safe External Link
</a>

Images

The <img> tag displays images:

<img src="photo.jpg" alt="Description of photo">

Required attributes:

  • src: Path to the image file (required)
  • alt: Alternative text description (ALWAYS include for accessibility)

Optional attributes:

  • width: Width in pixels
  • height: Height in pixels
  • title: Tooltip on hover

Complete Image Example

<img
  src="images/sunset.jpg"
  alt="Beautiful sunset over the ocean"
  width="600"
  height="400"
  title="Sunset photo">

Common Mistakes with Images

BAD: Missing alt text

<img src="photo.jpg">

GOOD: Always include alt text

<img src="photo.jpg" alt="Description of the photo">

Why? Screen readers need alt text to describe images to blind users.

Figure and Figcaption

Use <figure> to group an image with its caption:

<figure>
  <img src="chart.png" alt="Sales chart for 2026">
  <figcaption>Figure 1: Sales increased 25% in 2026</figcaption>
</figure>

<figure> can also contain code snippets, quotes, diagrams, etc.

6. Lists

HTML has three types of lists:

Unordered Lists (Bullet Points)

Use <ul> when order doesn't matter:

<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Oranges</li>
</ul>

Result:

  • Apples
  • Bananas
  • Oranges

Ordered Lists (Numbered)

Use <ol> when order matters:

<ol>
  <li>Preheat oven to 180°C</li>
  <li>Mix ingredients</li>
  <li>Bake for 30 minutes</li>
</ol>

Result:

  1. Preheat oven to 180°C
  2. Mix ingredients
  3. Bake for 30 minutes

Description Lists

Use <dl> for term-definition pairs:

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language</dd>

  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

Result:

HTML
HyperText Markup Language
CSS
Cascading Style Sheets

Nested Lists

You can put lists inside lists:

<ul>
  <li>Fruits
    <ul>
      <li>Apples</li>
      <li>Bananas</li>
    </ul>
  </li>
  <li>Vegetables
    <ul>
      <li>Carrots</li>
      <li>Lettuce</li>
    </ul>
  </li>
</ul>

When to Use Each Type?

List Type When to Use Example
<ul> Order doesn't matter Shopping list, features
<ol> Order matters Instructions, rankings
<dl> Term-definition pairs Glossary, FAQs

7. Tables

Tables are used to display data in rows and columns.

IMPORTANT: Tables are for DATA, NOT for page layout!
Use CSS Grid or Flexbox for page layout.

Basic Table Structure

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>John</td>
    <td>25</td>
  </tr>
  <tr>
    <td>Sarah</td>
    <td>30</td>
  </tr>
</table>

Tags:

  • <table>: Defines the table
  • <tr>: Table Row
  • <th>: Table Header (bold and centered)
  • <td>: Table Data (regular cell)

Complete Table Structure

<table>
  <caption>Student Grades</caption>
  <thead>
    <tr>
      <th>Name</th>
      <th>Subject</th>
      <th>Grade</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>John</td>
      <td>Math</td>
      <td>85</td>
    </tr>
    <tr>
      <td>Sarah</td>
      <td>Math</td>
      <td>92</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td colspan="2">Average</td>
      <td>88.5</td>
    </tr>
  </tfoot>
</table>

Additional tags:

  • <caption>: Table title/description
  • <thead>: Groups header rows
  • <tbody>: Groups body rows (main data)
  • <tfoot>: Groups footer rows (totals, summaries)

Colspan and Rowspan

Colspan (merge columns)

<table>
  <tr>
    <th colspan="2">Full Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>First: John</td>
    <td>Last: Smith</td>
    <td>25</td>
  </tr>
</table>

Rowspan (merge rows)

<table>
  <tr>
    <th rowspan="2">Name</th>
    <th>Subject 1</th>
    <th>Subject 2</th>
  </tr>
  <tr>
    <td>Math</td>
    <td>English</td>
  </tr>
</table>

Accessibility: Scope Attribute

Use scope to help screen readers:

<table>
  <tr>
    <th scope="col">Name</th>
    <th scope="col">Age</th>
  </tr>
  <tr>
    <th scope="row">John</th>
    <td>25</td>
  </tr>
</table>

Values:

  • scope="col": Header for column
  • scope="row": Header for row

8. Forms

Forms collect user input and send it to a server for processing.

Basic Form Structure

<form action="process.php" method="POST">
  <!-- Form inputs go here -->
  <button type="submit">Submit</button>
</form>

Form attributes:

  • action: URL where form data is sent
  • method: How to send data (GET or POST)

GET vs POST

Method When to Use Data Visibility
GET Search forms, filters Visible in URL
POST Login, registration, uploads Hidden (more secure)

Form Input Types

Text Input

<label for="username">Username:</label>
<input type="text" id="username" name="username">

Email Input

<label for="email">Email:</label>
<input type="email" id="email" name="email">

Password Input

<label for="password">Password:</label>
<input type="password" id="password" name="password">

Number Input

<label for="age">Age:</label>
<input type="number" id="age" name="age" min="0" max="120">

Date Input

<label for="birthday">Birthday:</label>
<input type="date" id="birthday" name="birthday">

Checkbox

<input type="checkbox" id="agree" name="agree">
<label for="agree">I agree to terms</label>

Radio Buttons

<p>Gender:</p>
<input type="radio" id="male" name="gender" value="male">
<label for="male">Male</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">Female</label>

File Upload

<label for="resume">Upload Resume:</label>
<input type="file" id="resume" name="resume" accept=".pdf,.doc">

Textarea

For multi-line text input:

<label for="message">Message:</label>
<textarea id="message" name="message" rows="5" cols="30"></textarea>

Select Dropdown

<label for="country">Country:</label>
<select id="country" name="country">
  <option value="">Choose a country</option>
  <option value="us">United States</option>
  <option value="uk">United Kingdom</option>
  <option value="es">Spain</option>
</select>

Fieldset and Legend

Group related form fields:

<fieldset>
  <legend>Personal Information</legend>

  <label for="fname">First Name:</label>
  <input type="text" id="fname" name="fname">

  <label for="lname">Last Name:</label>
  <input type="text" id="lname" name="lname">
</fieldset>

Button Types

<!-- Submit button (sends form) -->
<button type="submit">Submit</button>

<!-- Reset button (clears form) -->
<button type="reset">Reset</button>

<!-- Regular button (for JavaScript) -->
<button type="button">Click Me</button>

HTML5 Validation

Required Fields

<input type="text" name="username" required>

Pattern Validation

<!-- Only letters -->
<input type="text" pattern="[A-Za-z]+" title="Only letters">

<!-- Phone number -->
<input type="tel" pattern="[0-9]{9}" title="9 digits">

Min and Max

<input type="number" min="1" max="10">
<input type="text" minlength="3" maxlength="20">

Common Mistake: Missing Labels

BAD: Input without label

<input type="text" name="username">

GOOD: Always use labels

<label for="username">Username:</label>
<input type="text" id="username" name="username">

Why? Labels improve accessibility and usability. Users can click the label to focus the input.

Complete Form Example

<form action="register.php" method="POST">
  <fieldset>
    <legend>Registration Form</legend>

    <label for="username">Username:</label>
    <input type="text" id="username" name="username" required>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <label for="password">Password:</label>
    <input type="password" id="password" name="password"
           minlength="8" required>

    <label for="age">Age:</label>
    <input type="number" id="age" name="age" min="18" max="100">

    <label for="country">Country:</label>
    <select id="country" name="country" required>
      <option value="">Select a country</option>
      <option value="us">United States</option>
      <option value="es">Spain</option>
    </select>

    <input type="checkbox" id="terms" name="terms" required>
    <label for="terms">I agree to terms and conditions</label>

    <button type="submit">Register</button>
    <button type="reset">Clear Form</button>
  </fieldset>
</form>

9. Multimedia

Audio

The <audio> tag embeds sound files:

<audio controls>
  <source src="song.mp3" type="audio/mpeg">
  <source src="song.ogg" type="audio/ogg">
  Your browser does not support audio.
</audio>

Attributes:

  • controls: Shows play/pause/volume controls
  • autoplay: Starts playing automatically (usually blocked by browsers)
  • loop: Repeats when finished
  • muted: Starts muted

Video

The <video> tag embeds video files:

<video controls width="640" height="360">
  <source src="movie.mp4" type="video/mp4">
  <source src="movie.webm" type="video/webm">
  Your browser does not support video.
</video>

Attributes:

  • controls: Shows video controls
  • width and height: Video dimensions
  • poster: Image shown before video plays
  • autoplay: Auto-start (usually blocked)
  • loop: Repeat video

Iframe

Embed external content (YouTube videos, maps, etc.):

<!-- YouTube video -->
<iframe
  width="560"
  height="315"
  src="https://www.youtube.com/embed/VIDEO_ID"
  title="Video title"
  allowfullscreen>
</iframe>

<!-- Google Maps -->
<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="600"
  height="450"
  style="border:0;"
  allowfullscreen>
</iframe>

Tip: Most video platforms (YouTube, Vimeo) provide the embed code. Just copy and paste it into your HTML.

10. HTML5 Semantic Elements

HTML5 introduced many semantic elements to give meaning to content.

Article

Independent, self-contained content:

<article>
  <h2>Blog Post Title</h2>
  <p>Published on <time datetime="2026-10-15">October 15, 2026</time></p>
  <p>Article content...</p>
</article>

Section

Thematic grouping of content:

<section>
  <h2>Chapter 1</h2>
  <p>Chapter content...</p>
</section>

Aside

Content related to main content but not essential:

<aside>
  <h3>Related Links</h3>
  <ul>
    <li><a href="#">Link 1</a></li>
    <li><a href="#">Link 2</a></li>
  </ul>
</aside>

Time

Represents a date/time:

<p>Published on <time datetime="2026-10-15">October 15, 2026</time></p>
<p>Event starts at <time datetime="14:00">2:00 PM</time></p>

Mark

Highlighted/marked text:

<p>Search results for <mark>HTML</mark></p>

When to Use Each Element?

Element Use When
<article> Content makes sense on its own (blog post, news article)
<section> Thematic grouping with a heading (chapters, tabs)
<aside> Sidebar, related content, ads
<nav> Main navigation menus
<header> Introduction to page or section
<footer> Footer for page or section

11. Accessibility Basics

Accessibility means making your website usable by everyone, including people with disabilities.

Why Accessibility Matters

  • Legal requirement: Many countries require accessible websites
  • Inclusive: Everyone can use your website
  • Better SEO: Search engines prefer accessible sites
  • Better UX: Good for everyone, not just disabled users

Alt Text for Images

Always describe images with alt text:

BAD:

<img src="dog.jpg">

GOOD:

<img src="dog.jpg" alt="Golden retriever playing in the park">

Labels for Form Inputs

Always connect labels to inputs:

BAD:

<input type="text" name="username">

GOOD:

<label for="username">Username:</label>
<input type="text" id="username" name="username">

Semantic HTML

Use semantic tags instead of divs:

BAD:

<div class="navigation">...</div>

GOOD:

<nav>...</nav>

Heading Hierarchy

Use headings in order (don't skip levels):

BAD:

<h1>Main Title</h1>
<h4>Subtitle</h4>  <!-- Skipped h2 and h3 -->

GOOD:

<h1>Main Title</h1>
<h2>Subtitle</h2>

Descriptive Link Text

Link text should describe the destination:

BAD:

<a href="report.pdf">Click here</a>

GOOD:

<a href="report.pdf">Download 2026 Annual Report (PDF)</a>

Quick Accessibility Checklist

  • ✅ All images have alt text
  • ✅ All form inputs have labels
  • ✅ Use semantic HTML tags
  • ✅ Headings are in order (h1, h2, h3...)
  • ✅ Link text is descriptive
  • ✅ Color is not the only way to convey information
  • ✅ Text has good contrast with background

12. Best Practices

1. Always Use DOCTYPE

Start every HTML file with the DOCTYPE declaration:

<!DOCTYPE html>

2. Validate Your HTML

Use the W3C Validator to check for errors:

https://validator.w3.org/

3. Use Semantic Tags

Choose tags based on meaning, not appearance:

BAD:

<div class="header">
  <div class="nav">...</div>
</div>

GOOD:

<header>
  <nav>...</nav>
</header>

4. Keep HTML Clean and Indented

Proper indentation makes code readable:

BAD:

<div><p>Text</p><p>More text</p></div>

GOOD:

<div>
  <p>Text</p>
  <p>More text</p>
</div>

5. Separate HTML from CSS

Don't use inline styles:

BAD:

<p style="color: red; font-size: 20px;">Text</p>

GOOD:

<!-- HTML -->
<p class="highlight">Text</p>

<!-- CSS -->
.highlight {
  color: red;
  font-size: 20px;
}

6. Use Descriptive Class Names

BAD:

<div class="red-box">Error message</div>

GOOD:

<div class="error-message">Error message</div>

Why? "error-message" describes the purpose, not the appearance. If you change the color to orange, "red-box" would be misleading.

7. Close All Tags

Even though HTML5 is forgiving, always close tags:

BAD:

<p>Paragraph 1
<p>Paragraph 2

GOOD:

<p>Paragraph 1</p>
<p>Paragraph 2</p>

8. Use Lowercase for Tags

HTML is case-insensitive, but lowercase is standard:

BAD:

<DIV><P>Text</P></DIV>

GOOD:

<div><p>Text</p></div>

9. Add Comments

Document your code for future reference:

<!-- Navigation section -->
<nav>
  <!-- Main menu links -->
  <ul>
    <li><a href="home.html">Home</a></li>
  </ul>
</nav>

10. Test in Multiple Browsers

Always test your website in:

  • Chrome
  • Firefox
  • Safari
  • Edge

13. Basic SEO

SEO (Search Engine Optimization) helps your website appear in search results.

1. Title Tag

The most important SEO element:

<head>
  <title>Your Page Title - Your Site Name</title>
</head>

Tips:

  • Keep it under 60 characters
  • Include main keywords
  • Make it descriptive and unique per page
  • Put important words first

BAD:

<title>Home</title>

GOOD:

<title>Learn Web Development - Best HTML Tutorials 2026</title>

2. Meta Description

Appears in search results under the title:

<meta name="description" content="Learn HTML from scratch with our
comprehensive guide. Includes examples, exercises, and best practices.">

Tips:

  • Keep it under 160 characters
  • Write a compelling summary
  • Include keywords naturally

3. Heading Structure

Use headings to organize content:

<h1>Main Page Title</h1>
  <h2>Section 1</h2>
    <h3>Subsection 1.1</h3>
    <h3>Subsection 1.2</h3>
  <h2>Section 2</h2>

Rules:

  • One h1 per page
  • Don't skip heading levels
  • Include keywords in headings

4. Alt Text for Images

Search engines read alt text:

<img src="laptop.jpg"
     alt="Person typing on laptop learning HTML programming">

5. Clean URLs

BAD:

www.example.com/page.php?id=123&cat=5

GOOD:

www.example.com/html-tutorial

Basic SEO Checklist

  • ✅ Unique, descriptive title tag (under 60 chars)
  • ✅ Compelling meta description (under 160 chars)
  • ✅ One h1 per page with main keyword
  • ✅ Logical heading hierarchy (h1, h2, h3...)
  • ✅ Alt text on all images
  • ✅ Semantic HTML structure
  • ✅ Clean, readable URLs

Summary

Congratulations! You've learned the fundamentals of HTML. Here's what you should remember:

Key Concepts

  • HTML is a markup language for structuring web content
  • Every HTML document needs DOCTYPE, html, head, and body
  • Semantic tags (header, nav, main, article, footer) improve SEO and accessibility
  • Forms collect user input with various input types
  • Tables display data in rows and columns (not for layout)
  • Accessibility is critical: use alt text, labels, and semantic HTML
  • Separate structure (HTML) from style (CSS)

Next Steps

  1. Practice building complete HTML pages
  2. Learn CSS to style your HTML
  3. Validate your HTML at validator.w3.org
  4. Experiment with different layouts and structures
  5. Study real websites using browser DevTools (F12)

Learning Tip: The best way to learn HTML is by doing. Build real projects, make mistakes, and learn from them. Start simple and gradually increase complexity.
