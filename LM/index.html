Presentación de la asignatura

Base sólida en HTML, CSS y ecosistema web para crear interfaces accesibles, rápidas y mantenibles.

¡Bienvenidas y bienvenidos al módulo de Lenguaje de Marcas! En esta asignatura construiremos la base técnica y conceptual para maquetar y dar estilo a interfaces web de calidad. Trabajaremos con HTML (estructura), CSS (presentación) y TypeScript (interacción con tipado estático), siempre con foco en accesibilidad, rendimiento y buenas prácticas.

Enfoque integrador: Este módulo se trabaja de forma coordinada con todos los módulos de 1º DAW, especialmente con Programación (Java) y Bases de Datos, para desarrollar aplicaciones web completas desde el principio del curso.

1. Objetivos del curso

El objetivo principal de este módulo es proporcionar al alumnado las competencias necesarias para desarrollar interfaces web modernas, accesibles y mantenibles, con un enfoque integrador que conecta con todos los módulos de 1º DAW, especialmente con Programación y Bases de Datos.

Los contenidos están muy orientados al desarrollo web completo, priorizando el trabajo en proyectos reales que integran front-end (HTML, CSS, TypeScript) con back-end (Java) y persistencia (Bases de Datos).

Competencias específicas:

  • Diferenciar roles de HTML, CSS y TypeScript y aplicarlos de forma semántica y mantenible.
  • Dominar CSS moderno: cascada, especificidad, box model, layout con Flexbox y Grid, responsive y variables.
  • Construir componentes accesibles (teclado, :focus-visible, contraste WCAG) y optimizados.
  • Desarrollar con TypeScript: tipado estático, interfaces, clases, módulos y buenas prácticas.
  • Integrar herramientas y metodologías (BEM, organización por capas, Git) en proyectos integradores.
  • Consumir APIs REST desde TypeScript para conectar con aplicaciones Java y bases de datos.
  • Trabajar en proyectos colaborativos que combinan todos los módulos del ciclo.

2. Metodología y dinámica

Enfoque práctico y orientado a proyectos

Este módulo sigue una metodología eminentemente práctica, donde la teoría se introduce de forma progresiva y siempre aplicada a casos reales de desarrollo web. El objetivo es que puedas trabajar en proyectos funcionales desde el inicio del curso.

Estructura temporal por evaluaciones

Primera Evaluación: Fundamentos y base para proyectos

Durante la primera evaluación se presentarán contenidos mínimos de todos los Resultados de Aprendizaje (RAs) del módulo:

  • HTML semántico básico (estructura, formularios)
  • CSS fundamental (selectores, box model, Flexbox básico)
  • TypeScript básico (tipos, funciones, DOM, eventos)
  • XML y validación (DTD, XSD)
  • Markdown para documentación

El objetivo es que, al finalizar la primera evaluación, dispongas de las herramientas necesarias para comenzar a trabajar en proyectos integradores con los demás módulos (Programación, Bases de Datos).

Segunda Evaluación: Profundización y primer proyecto

Se profundiza en todos los RAs trabajados en la primera evaluación:

  • HTML avanzado (accesibilidad, SEO, formularios complejos)
  • CSS avanzado (Grid, animaciones, variables, responsive avanzado)
  • TypeScript completo (clases, interfaces, módulos, async/await, fetch)
  • Consumo de APIs REST
  • Organización de proyectos (BEM, arquitectura CSS)

Desarrollarás un proyecto práctico que integra front-end completo (HTML, CSS, TypeScript) con back-end (Java) y bases de datos.

Tercera Evaluación: Proyecto integrador final

La tercera evaluación se centra en el desarrollo de un proyecto integrador completo que combina todos los módulos de 1º DAW:

  • Lenguajes de Marcas (HTML, CSS, TypeScript)
  • Programación (Java - lógica de negocio y API REST)
  • Bases de Datos (diseño, implementación, consultas)
  • Entornos de Desarrollo (Git, testing, CI/CD)
  • Sistemas Informáticos (despliegue, configuración)

Trabajo con proyectos

Validación con el equipo educativo: Todos los proyectos deberán ser presentados y validados con el equipo educativo antes de su entrega final. Esto asegura que el proyecto cumple con los requisitos de todos los módulos.

Todos los RAs en todas las evaluaciones

Se trabajan todos los Resultados de Aprendizaje en todas las evaluaciones, con diferentes niveles de profundidad:

  • 1ª Eval: Conceptos básicos de todos los RAs
  • 2ª Eval: Profundización en todos los RAs + proyecto
  • 3ª Eval: Dominio avanzado aplicado al proyecto integrador

Actividades de aprendizaje

  • Clases prácticas con demostraciones y laboratorios paso a paso
  • Retos cortos y ejercicios con solución y rúbricas claras
  • Desarrollo de proyectos individuales y en equipo
  • Presentaciones ante el equipo educativo
  • Trabajo colaborativo con Git y metodologías ágiles

3. Unidades

UD1 Lenguajes de Marcas

Explorarás qué es un lenguaje de marcas y para qué se usa en la web y en el intercambio de datos. Trabajarás con XML (estructura, atributos, namespaces), su validación con DTD y XSD, y conocerás Markdown para documentación técnica. Practicarás con pequeños documentos bien formados, crearás un esquema sencillo para validar datos y aprenderás a usar validador online.

Entregable: Colección de ejemplos XML válidos + una breve guía en Markdown.

UD2 HTML

Construirás la estructura de páginas accesibles usando las etiquetas semánticas de HTML5 (<header>, <main>, <section>, <article>, <nav>, <footer>). Verás imágenes, listas, tablas, enlaces internos/externos, rutas y formularios (inputs HTML5, validación nativa). Practicarás buenas prácticas de accesibilidad (texto alternativo, jerarquía de encabezados, labels) y validarás el documento con el validador del W3C.

Entregable: Mini-sitio multipágina con navegación coherente y formulario funcional.

UD3 CSS

Dominarás la cascada, herencia y especificidad, los selectores clásicos y modernos (:is(), :where(), :has()), y el box model. Pasarás al layout moderno con Flexbox y Grid (componentes, áreas, auto-fit), responsive con media queries, tipografía fluida (clamp()) y variables CSS. Añadirás transiciones y animaciones respetando prefers-reduced-motion.

Entregable: Landing responsive con componentes reutilizables y efectos de interacción.

UD4 TypeScript

Introducirás interactividad con TypeScript: sistema de tipos estático, interfaces y types, funciones tipadas y módulos, DOM y eventos con tipos, fetch para consumir APIs REST con tipos de respuesta, y renderizado dinámico. Verás patrones básicos (delegación de eventos, separación de lógica y vista) con el beneficio del tipado estático, gestión de errores con tipos, y buenas prácticas de accesibilidad (gestión del foco, ARIA mínima). Aprenderás a configurar TypeScript, usar el compilador y aprovechar las ventajas del desarrollo con autocompletado y detección temprana de errores.

Entregable: Aplicación TypeScript que consume una API REST (desde Java + BD) y renderiza datos con filtrado e interacción, totalmente tipada.

Proyecto

Aplicarás todo lo aprendido en un proyecto completo: definición de contenido, diseño visual y responsive, accesibilidad básica, interactividad con JS y, si procede, plantillas en servidor. Trabajarás con control de versiones, organización del CSS (BEM y capas) y despliegue estático.

Entregables: repositorio limpio documentado, demo desplegada y retrospectiva técnica breve.

La evaluación está diseñada para ser progresiva y acumulativa, valorando tanto los conocimientos teóricos como las competencias prácticas adquiridas a lo largo del curso.

2ª Evaluación • Prueba objetiva

3ª Evaluación Proyecto integrador 100% Proyecto final que integra todos los módulos de 1º DAW. La nota depende del desarrollo del front-end completo (HTML, CSS, TypeScript) y su correcta integración con back-end (Java) y bases de datos. Presentación y defensa ante equipo educativo.

Cálculo de la nota final del módulo

La nota final del curso se calculará de la siguiente manera:

  • 20% - Media de las pruebas objetivas: Media aritmética de todas las pruebas objetivas realizadas a lo largo del curso (1ª evaluación + 2ª evaluación).
  • 80% - Proyecto final: El proyecto integrador de la 3ª evaluación, que incluye el proyecto de la 2ª evaluación mejorado y ampliado con la integración de todos los módulos.

Fórmula: Nota Final = (Media Pruebas Objetivas × 0.20) + (Proyecto Final × 0.80)

Este sistema refuerza el enfoque práctico del módulo, dando mayor peso al desarrollo de competencias aplicadas en proyectos reales.

⚠️ ¡A tener en cuenta!
Para cada prueba que se realice (tanto pruebas objetivas como proyectos), se os puede pedir en cualquier momento una prueba de validación para verificar el trabajo realizado. Si no se supera dicha prueba de validación, la prueba o proyecto correspondiente se calificará con 0.

Esta medida garantiza que el trabajo presentado es realmente vuestro y que habéis adquirido las competencias evaluadas.

La planificación detallada (resultados de aprendizaje, actividades y ponderaciones) se recoge en la programación del curso.
